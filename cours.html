⚡ Synthèse Essentielle — Séquence 01

1 — La chaîne d'information

ACQUÉRIR (Capteurs) → TRAITER (Arduino Uno R3) → COMMUNIQUER (LED, Buzzer).

💡 À retenir : Un bouton est une entrée (IN). Une LED ou un buzzer sont des sorties (OUT).

2 — Formes d'informations

  • Valeur numérique : 27 cm, 21.4 °C (Seuils, calculs, affichage).
  • État logique / TOR (Tout Ou Rien) : Signal binaire (HIGH = 5V / LOW = 0V).

3 — Lecture d'une condition (Arduino)

if (distance <= 30) {
  digitalWrite(LED, HIGH); // Allume la LED si la condition est vraie
}

💡 Opérateurs : <= (inférieur ou égal), == (égal à), != (différent de).
