Analyse du système & Chaîne d'information

A1. Fonctions des éléments du système

Ma réponse :
• Acquérir la distance : capteur de distance Grove.
• Traiter les informations : Arduino Uno R3.
• Communiquer au conducteur : LED Grove et buzzer Grove.
• Agir sur le système : bouton Grove.

✔ Correct

A2. Classification dans la chaîne d'information

Ma réponse : ACQUÉRIR: Capteur Grove | TRAITER: Arduino Uno R3 | COMMUNIQUER: LED Grove et buzzer Grove.

⚠️ À compléter
Correction : ACQUÉRIR : Capteur de distance Grove + Bouton Grove. TRAITER : Arduino Uno R3. COMMUNIQUER : LED Grove + Buzzer Grove.
Remarque : Le bouton est aussi une entrée du système : il permet d'acquérir une information provenant de l'utilisateur.

A3. Nature des informations

Ma réponse : Capteur de distance = analogique | Bouton poussoir = numérique.

❌ À corriger
Correction : Le capteur de distance fournit une valeur numérique de distance mesurée. Le bouton fournit un état logique / TOR (0 ou 1). Il ne faut pas confondre « analogique / numérique » avec le rôle d'une entrée.

Analyse du programme (C1 - C3)

C1. Instructions de commande

⚠️ Partiellement correct
• Acquisition : distance = ultrasonic.MeasureInCentimeters();
• Affichage : Serial.println(distance);
• Allumage de la LED : digitalWrite(LED, HIGH);
La condition if (distance <= 30) ne commande pas directement la LED : elle décide si les instructions du bloc doivent être exécutées.

C2. Rôle de la condition if

✔ Correct dans l'idée
if (distance <= 30) signifie : si la distance est inférieure ou égale à 30 cm, le bloc suivant est exécuté.

C3. Tests d'états

• 45 cm : LED éteinte.
• 25 cm : LED allumée.
• 10 cm : LED allumée.

D1. Structure multi-conditions

✔ Correct
• Si distance ≤ 15 cm : LED ON, buzzer ON.
• Sinon si distance ≤ 30 cm : LED ON, buzzer OFF.
• Sinon : LED OFF, buzzer OFF.
