⚠️ Erreur clé relevée : Capteur bloqué à 0 = dysfonctionnement à signaler et analyser (vérifier câblage D7 et moniteur série).

Corrections incontournables :

  • Chaîne d'information : L'acquisition se fait par le capteur de distance ET le bouton poussoir (qui est aussi une entrée utilisateur).
  • Nature des signaux : Le capteur de distance renvoie un signal numérique, le bouton fournit un état logique / TOR.
  • Instructions Arduino :
    distance = ultrasonic.MeasureInCentimeters(); (Acquérir)
    digitalWrite(LED, HIGH); (Instruction de commande d'allumage)

Logique Radar de Recul attendue :

if (distance <= 15) { // Zone 1 : Danger (LED ON, buzzer ON) }
else if (distance <= 30) { // Zone 2 : Intermédiaire (LED ON, buzzer OFF) }
else { // Zone 3 : Sécurité (LED OFF, buzzer OFF) }
